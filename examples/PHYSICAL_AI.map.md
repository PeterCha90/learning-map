# Physical AI

## Physical AI란? (vs 일반 AI) [2/5]
- [x] 몸이 있는 AI — ChatGPT는 몸이 없고, Physical AI는 로봇이라는 몸으로 현실에서 움직인다.
- [x] 물리적 실수의 대가 — 로봇 팔이 판단을 틀리면 컵을 깨거나 떨어뜨린다. "다시 해줘"로 되돌릴 수 없다.
- [ ] 기존 로봇과의 차이 — 정해진 규칙만 하는 로봇 vs 처음 보는 상황에도 일반화하는 로봇

## 감지→판단→행동 루프 [2/5]
- [x] 카메라와 좌표 인식 — 좌표는 누가 넣어주지 않는다. 로봇이 카메라로 보고 자기 위치 기준으로 알아낸다.
- [x] 오픈 루프의 한계 — 딱 한 번 보고 움직이면, 도중에 컵이 옮겨져도 모른 채 허공을 잡는다.
- [x] 클로즈드 루프 — 움직이는 동안에도 계속 보고 다시 계산해야 한다.
- [ ] 지연과 연산의 트레이드오프
  - [ ] 큰 모델은 느리다
  - [ ] 빠른 반사 + 느린 계획
